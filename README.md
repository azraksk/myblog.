# 📝 Blog PHP Project
This project is a simple blog web application developed using PHP, MySQL, Bootstrap, and CSS.

It allows users to read blog posts, manage their profiles, and provides an admin panel for content management.

The project was built as a learning-oriented full-stack PHP project, focusing on backend logic, database integration, and clean UI structure.

# 🚀 Features
## 👤 User Features
User authentication (Sign up / Log in / Log out)

User profile page

Edit “About Me” section

Upload profile photo

Responsive navigation bar with dropdown menu

Blog post listing

Search functionality

Read full blog posts


# 🛠 Admin Panel

View all blog posts

Add new blog posts

Edit existing posts

Delete posts

Styled admin table with actions


# 🧱 Technologies Used

PHP (Procedural & PDO)

MySQL

Bootstrap 5

HTML5 & CSS3

Session-based authentication


# 🎯 Purpose of the Project

Practice PHP & MySQL integration

Understand session-based authentication

Learn CRUD operations

Build a structured, reusable layout (navbar, header, footer)

Improve frontend & backend coordination
